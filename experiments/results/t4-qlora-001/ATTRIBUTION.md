# Data attribution

Question/SQL/schema excerpts derive from Spider by Tao Yu and collaborators (EMNLP 2018), published by XLang NLP Lab:
https://huggingface.co/datasets/xlangai/spider
https://yale-lily.github.io/spider

The upstream dataset declares Creative Commons Attribution-ShareAlike 4.0:
https://creativecommons.org/licenses/by-sa/4.0/

The excerpts have been filtered, split, formatted into conversations and supplemented with model predictions and analysis. Dataset-derived content retains CC BY-SA 4.0 attribution; repository software licensing does not replace the dataset terms.

Database fixtures are fetched from the pinned public mirror:
https://huggingface.co/datasets/prem-research/spider

The source revisions and database hashes are in spider/manifest.json. Database binaries and model weights are not stored in this directory.
